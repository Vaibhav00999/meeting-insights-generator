        How it works — 3 modalities, 0 servers

        1. Speech → Text: Web Speech API (Chrome/Edge) for live recording; audio files play back for live dictation; .txt/.vtt/.srt transcripts parsed locally.
        2. Text → Insight: local extractive summarisation in JavaScript — sentence scoring on action verbs, decisions, dates, numbers, speaker changes and keyword density. No API key, no network call, works offline.
        3. Text → Visual world: speaker-share bars, a colour-coded timeline, and a keyword cloud rendered from the same transcript — exportable as Markdown / plain text.

        Privacy: audio and text never leave this page. The demo transcript is built in. Accuracy note: summarisation is extractive, so it quotes the meeting verbatim — it cannot invent a decision that was not said. See README.md for the measured demo results.
